שלב 1 — יצירת גיליון Google
  1. פתחי sheets.new (ייפתח גיליון חדש).
  2. תני לו שם: שמפ (לחצי על "Untitled spreadsheet" למעלה).
שלב 2 — הוספת Apps Script
  1. בגיליון: תפריט Extensions ← Apps Script.
  2. מחקי את הקוד שיש (function myFunction...) והדביקי במקומו את הקוד הזה:
  3. לחצי על 💾 Save (Ctrl+S).
  4. לחצי Deploy ← New deployment.
  5. לצד "Select type" בחרי Web app.
  6. בשדה Who has access בחרי Anyone.
  7. לחצי Deploy → אשרי הרשאות (Allow) → העתיקי את ה-Web app URL.
